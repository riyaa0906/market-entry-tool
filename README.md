# Market Entry Analysis Tool — Indian D2C Skincare

## Problem Statement
Should a new brand enter the Indian D2C skincare market in 2026?

## Methodology
- TAM/SAM/SOM market sizing using public market reports (IBEF, Inc42, Statista)
- Porter's Five Forces scoring across 5 competitive dimensions
- Competitor landscape analysis across 5 major players

## Key Findings
- Market growing at 26% CAGR but highly competitive (rivalry score 5/5)
- Tier 2 cities growing 2x faster than metros — underpenetrated opportunity
- Recommended entry point: Men's skincare or sensitive skin segment, Tier 2 cities, quick commerce first

## Tools Used
Python, Streamlit, Pandas, Plotly
